## Description
A generator to come up with ideas for original characters. 

## Features
- Feature 1
	- It will produce a basic sentence with a noun and 1-2 adjectives that are randomly selected from a dictionary.
- Feature 2
	- It will display that sentence to the screen in a long image, similar to a fortune cookie.
- Feature N 
	- It will also allow the user to input adjectives and nouns of their own.

## Challenges
- Creating a user interface, I would like there to be a window that opens and the user clicks a button to generate their oc fortune
- Differentiating between nouns and adjectives when the user inputs them
- Producing images

## Outcomes
Ideal Outcome:
- Ideally it is a seamless application that allows a user to open it, click a button and recieve an image that looks like a slip of fortune cookie paper with the oc that they can now create. It will have the OC's species and two other adjectives/attributes about them to make them unique. 

The button will have a sound when hovered over, pressed and once it has created the image. 

The user can be able to add their own words to the pool.

Minimal Viable Outcome:
- A script to create a "fortune cookie" style image with sentence prompt for an OC the artist can make. (Just the image creation and random sentence logic, minus the UI)
