# Title
Original Character Fortune Cookie

## Repository
https://github.com/evkworkshop123/oc_fortune-cookie/commit/4b4bd40c9aca533b93450c1a0264bd027bcd568f

## Description
A generator to come up with ideas for original characters. The program will generate a prompt that the user can use to make an original character. This program is great for digital art and media, as it is a fun way to practice drawing or modelling. The user can build on what they are prompted with in any way that they like once the idea is sparked by the program. All of it is wrapped in a fun "fortune cookie" style image.  

## Features
- Feature 1
	- Displays a randomized sentence with a noun and 1-2 adjectives that are randomly selected from a dictionary in a long, "fortune cookie" styled image
- Feature 2
	- UI with a button the user can click to generate their slip.
- Feature N 
	- It will also allow the user to input adjectivesp and nouns of their own.

## Challenges
- Creating a user interface, I would like there to be a window that opens and the user clicks a button to generate their oc fortune image
- Differentiating between nouns and adjectives when the user inputs them
- Producing images

## Outcomes
Ideal Outcome:
- Ideally it is a seamless application that allows a user to open it, click a button and recieve an image that looks like a slip of fortune cookie paper with the oc that they can now create. It will have the OC's species and two other adjectives/attributes about them to make them unique. 

The button will have a sound when hovered over, pressed and once it has created the image. 

The user can be able to add their own words to the pool.

Minimal Viable Outcome:
- A script to create a "fortune cookie" style image with sentence prompt for an OC the artist can make. (Just the image creation and random sentence logic, minus the UI)

## Milestones

- Week 1
  1. Random selection and sentence mixing logic
  2. Create the dictionary of words.

- Week 2
  1. Apply finished sentences to an image
  2. Create UI, (at least the button needs to function)

- Week N (Final)
  1. Polish UI
  2. Add ability for user input of words
